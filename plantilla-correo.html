# Guía de Uso - Nuevas Características ## 1. Botón de Favorito en la Cotizadora ### Ubicación Justo después de completar los datos del cliente (card 1), antes de "Arma el plan". ### Apariencia ``` ┌─────────────────────────────────┐ │ ☆ AÑADIR A FAVORITOS │ ← Grande, visible, azul └─────────────────────────────────┘ ``` ### Cómo funciona 1. **Al pulsar el botón:** - Si NO es favorito → cambia a `★ QUITAR DE FAVORITOS` - Si YA es favorito → cambia a `☆ AÑADIR A FAVORITOS` - Se muestra mensaje confirmatorio 2. **El estado se guarda:** - Cuando pulsas "➕ Historial" - Si es cliente nuevo → se marca como favorito o no según el botón - Si es cliente existente → mantiene su estado anterior ### Ejemplo de flujo ``` Paso 1: Rellenar datos del cliente Paso 2: Pulsar ★ QUITAR... para marcar como favorito (cambia a ☆) Paso 3: Armar plan con las opciones necesarias Paso 4: Pulsar "➕ Historial" Resultado: Cliente se guarda como FAVORITO ★ ``` --- ## 2. Favorito en el Historial ### Nueva columna La tabla del historial ahora tiene una **primera columna** con la estrella: ``` ★ │ Fecha │ Empresa │ Contacto │ Correo ... ──────┼──────────┼──────────────┼───────────────┼───────── ☆ │ 10/01/25 │ Acme Corp │ Juan Pérez │ juan@... ★ │ 09/01/25 │ Globex Inc │ Karen Morales │ karen@... ☆ │ 08/01/25 │ XYZ Ltd │ Roberto Silva │ rober@... ``` ### Cómo usar - **Clic en la estrella ☆** → Marca como favorito (se vuelve ★) - **Clic en la estrella ★** → Quita de favorito (se vuelve ☆) - El cambio es inmediato - Se sincroniza automáticamente con el botón de la cotizadora ### Ventajas - Identifica rápidamente tus clientes más importantes - Un clic para cambiar el estado - Se mantiene cuando se actualiza la cotización --- ## 3. Sin Duplicados en Historial ### Comportamiento anterior (problemático) ``` Paso 1: Guardar cliente "Juan Pérez" para plan Condominio → Se crea registro 1 Paso 2: Abrir el mismo cliente, cambiar a plan 24/7 Paso 3: Pulsar "➕ Historial" → Se creaba REGISTRO 2 (duplicado) Resultado: Dos Juan Pérez en el historial 🚫 ``` ### Comportamiento nuevo (mejorado) ``` Paso 1: Guardar cliente "Juan Pérez" para plan Condominio → Se crea registro Paso 2: Abrir el mismo cliente, cambiar a plan 24/7 Paso 3: Pulsar "➕ Historial" → El registro se ACTUALIZA con la nueva cotización Resultado: Un solo Juan Pérez con la última cotización ✅ ``` ### Qué identifica como "el mismo cliente" El sistema compara estos datos (en orden de importancia): 1. **RUT** - Si coinciden, es el mismo cliente - "12.345.678-9" = "12345678-9" (se ignoran caracteres especiales) 2. **Correo** - Si coinciden, es el mismo cliente - "juan@mail.com" = "juan@mail.com" (insensible a mayúsculas) 3. **Teléfono** - Si coinciden, es el mismo cliente - "+56912345678" = "56 9 1234 5678" (se ignoran espacios) 4. **Nombre + Empresa** - Si ambos coinciden, es el mismo cliente - "Juan Pérez" + "Acme Corp" identifica al cliente 5. **Nombre + Correo** - Si ambos coinciden, es el mismo cliente - "Juan Pérez" + "juan@mail.com" identifica al cliente ### Ejemplo práctico ``` Primera cotización: Contacto: Karen Morales Correo: karen@empresa.cl Empresa: Globex Inc Teléfono: +56 9 1234 5678 Plan: Condominio Valor: 2,6 UF Segunda cotización (mismo cliente): Contacto: karen morales ← Letras minúsculas Correo: karen@empresa.cl Empresa: Globex Inc Plan: 24/7 ← Plan diferente Valor: 3,3 UF Resultado: Se reconoce como el mismo cliente El registro se ACTUALIZA, no se duplica El histórico muestra: Karen Morales con plan 24/7 y 3,3 UF ✅ ``` ### Insensible a pequeñas diferencias ``` Estos se consideran el MISMO cliente: √ "Karen Morales" vs "karen morales" √ "karen morales" (dos espacios) vs "karen morales" (un espacio) √ "Karen Moráles" vs "karen morales" (acentos) √ "juan@mail.com " (espacios extras) vs "juan@mail.com" Estos se consideran CLIENTES DIFERENTES: ✗ "Juan Pérez" sin teléfono vs "Juan Pérez" con otro teléfono ✗ "Karen" (nombre corto) vs "Karen Morales" (nombre completo) ``` --- ## 4. Favorito se Preserva al Actualizar ### Comportamiento ``` Cliente Juan Pérez, marcado como ★ favorito Cotización 1: Plan Condominio, 2,6 UF ↓ Se vuelve a abrir para cambiar la cotización Cotización 2: Plan 24/7, 3,3 UF ↓ Pulsar "➕ Historial" Resultado: ┌─────┬──────────┬──────────┐ │ ★ │ Juan P. │ 24/7 │ ← Sigue siendo favorito ★ └─────┴──────────┴──────────┘ La estrella se MANTIENE ``` ### Importante - El favorito pertenece al **cliente**, no a la **cotización** - Si marcas un cliente como ★, seguirá siéndolo aunque cambies su cotización - Si lo desmarc as con ☆, permanecerá desmarcado en futuras actualizaciones --- ## 5. Mantenimiento de Datos ### Qué se ACTUALIZA cuando hay cliente existente ``` ✅ Plan (se reemplaza con el nuevo) ✅ Módulos (se reemplaza con los nuevos) ✅ Valor UF/mes (se recalcula) ✅ Valor CLP/mes (se recalcula) ✅ Período (se actualiza) ✅ Selecciones (sel) (se reemplazan con las nuevas) ✅ Fecha (se actualiza a hoy) ✅ UF día (se reemplaza si es diferente) ✅ IVA (se actualiza si cambió) ``` ### Qué se PRESERVA cuando hay cliente existente ``` ✅ Estado actual (Borrador / Enviada / En negociación / etc) ✅ Agenda (fecha agendada) ✅ Observaciones (notas internas) ✅ Favorito (★ o ☆) ✅ ID del registro (identificador único, no cambia) ``` ### Qué se CREA si es cliente nuevo ``` Nueva entrada en historial con: ✅ ID único (timestamp) ✅ Fecha de creación (hoy) ✅ Todos los datos de cotización ✅ Estado: "Borrador" (por defecto) ✅ Favorito: NO marcado (☆) ``` --- ## 6. Flujo de Trabajo Optimizado ### Escenario 1: Prospecto nuevo ``` 1. Rellenar datos (nombre, correo, empresa) 2. Opcionalmente: marcar como ★ favorito si es importante 3. Armar plan con opciones 4. Pulsar "➕ Historial" → Se crea nuevo registro → Se guarda con el estado de favorito que elegiste ``` ### Escenario 2: Cliente que necesita opciones nuevas ``` 1. Pulsar "Reabrir" (↩) en el historial → Se carga la cotización anterior → El favorito se restaura también 2. Cambiar plan/opciones 3. Pulsar "➕ Historial" → El registro se ACTUALIZA → El favorito se MANTIENE → NO se crea duplicado ``` ### Escenario 3: Cliente importante que necesita seguimiento ``` 1. Crear cotización normal 2. Marcar como ★ en la cotizadora 3. Guardar en historial 4. En el historial, puedes ver fácilmente todos los ★ favoritos 5. Al actualizar la cotización, el ★ se preserva automáticamente ``` --- ## 7. Mensajes de Confirmación El sistema muestra estos mensajes toast: ### Al pulsar el botón de favorito (cotizadora) ``` ⭐ Marcado como favorito ← Si lo marcas ☆ Quitado de favoritos ← Si lo desmarc as ``` ### Al guardar en historial ``` ✏️ Cotización actualizada para [nombre] ← Si actualiza cliente existente ➕ Guardado en historial (N) ← Si crea nuevo registro ``` ### Al cambiar favorito en historial ``` Sin mensaje directo (pero la estrella cambia inmediatamente) ``` --- ## 8. Preguntas Frecuentes ### P: ¿Se perderá mi historial anterior? **R:** No. Los registros anteriores se mantienen tal cual. Solo los nuevos tendrán el campo `favorito` (☆ por defecto si no lo marcas). ### P: ¿Qué pasa si dejo un cliente como "Enviada" y luego lo actualizo? **R:** El estado "Enviada" se mantiene. La cotización se actualiza, pero el estado administrativo se preserva. ### P: ¿Puedo marcar/desmarcar favoritos rápidamente? **R:** Sí. Un clic en la estrella en el historial es suficiente. El cambio es inmediato. ### P: ¿El favorito se sincroniza entre pestañas/dispositivos? **R:** Se sincroniza en el navegador actual. Si uses Google Drive (⬆ Importar/Respaldo), el favorito se guardaría en el JSON. ### P: ¿Cómo sé si un cliente ya existe? **R:** No hay notificación explícita. Solo verás que se actualizó (mensaje: "✏️ Cotización actualizada") en lugar de crear uno nuevo. ### P: ¿Qué pasa si cambio solo un campo y guardo? **R:** Si es cliente existente, todo se actualiza de todas formas. El sistema asume que es una "revisión" del mismo cliente. --- ## 9. Casos de Uso Especiales ### Fusionar dos clientes (accidental) Si accidentalmente guardaste el mismo cliente dos veces (antes de esta actualización): ``` Opción 1: Eliminar el duplicado (🗑 en historial) Opción 2: Consolidar datos manualmente (Reabrir, actualizar, guardar) ``` ### Cambiar solo el teléfono/email ``` 1. Pulsar "Reabrir" en historial 2. Cambiar el teléfono/email 3. Pulsar "➕ Historial" 4. El sistema lo reconocerá como el mismo cliente (por otros datos) 5. Se actualiza el registro existente ``` ### Identificar favoritos rápidamente ``` En el historial, todos los ★ son tus clientes importantes Puedes filtrar mentalmente o usar Ctrl+F para buscar ★ ``` --- ## Notas Técnicas - **Almacenamiento:** localStorage (sv_historial_v1) - **Sincronización:** Google Drive (si está habilitado) - **Normalización:** Se usa solo para comparación, los datos originales se mantienen intactos - **Respaldos:** El campo `favorito` se incluye en descargas JSON e importaciones --- **Versión:** 1.0 **Fecha:** Enero 2025 **Compatible con:** Secretaría Virtual Geimser (Fases 1-3 completadas)
